# 自带的表情包

她用 `phone_message` 发 QQ 消息时可以写 `[表情包:名字]`，插件就把这里同名的图片单独发成一条（QQ 里显示成表情包）。
**文件名（去掉扩展名）就是名字**，名字会全部列在她的规则里，所以名字要能看出意思（「收到（敬礼）」「疑惑：这用户发的啥啊」）。
支持 `.gif`、`.png`、`.jpg`、`.jpeg`、`.webp`。

- 这些是仓库作者为默认人设「大肥鱼」（蓝发鲸鱼少女）准备的。**不在本项目的 Apache-2.0 许可范围内**，来源和许可见下面。
- 不想用：插件配置 `qq.builtinStickers: false`。
- 用你自己的：放进 `~/.dsh/little-house/stickers/`（`stateDir` 下的 `stickers` 文件夹），和这里同名的会盖过这里的。改了文件夹要重启 DSH，她的规则里才会更新名单。
- 她收到别人发的表情包时看到的是 `[表情包]` 和图片本身。
