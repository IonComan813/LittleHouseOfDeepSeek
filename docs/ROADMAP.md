## M4 + 合并会话实测（2026-11-14）

- **记忆整理**：把前面测试留下的一天（日记两段 + 私聊 + 群聊记录）当作 11-13 整理。约半分钟出结果：一段当天概括、5 条想做的事（「等逗猫棒送到再试试和团子玩」「下次炒菜要好好守着锅」……）、5 条记得的事、3 个人。
- **新的一天**：会话第一条消息开头是日期 +「## 你的记忆」。她在院子里把第三块菜地也种上萝卜，日记里写「逗猫棒还没到，邮箱空空的，有点失望」——接上了记忆里「等逗猫棒送到」。
- **自由活动中途来消息**：主人问「在忙什么呀？逗猫棒到了没」，消息在她两段 `house_do` 之间插进来；她先 `phone_message` 回（「逗猫棒还没到，邮箱是空的 [表情:发呆]」），再接着做事、写日记、结束。
- **自由活动以外**：主人让她拍张照，她 `phone_message(photo: true)`。语音消息在桥这里挡掉，没有叫她。
- 12 次模型调用，94% 缓存命中。

## M5 实测（2026-11-14，假 NapCat + DSH 0.2.2-rc.2 + deepseek-flash）

（这一节是合并会话之前的版本：那时每个聊天每天一个单独的会话，回复是她直接写的文字。）


- **私聊 + 图片**：主人发来一张小屋截图问「像什么」，她先 `house_status` 看了看，回「这不是我家吗」「中间站着的那个是我吧，尾巴露在外面呢 [表情:偷笑]」，分三条发出，表情变成了真的 QQ 表情。
- **拍照**：主人让她拍张家里的照片，她 `house_photo(caption: "刚爬起来拍的，屋里有点乱，别笑话我")`，然后「我刚从床上爬起来，头发肯定乱糟糟的 [表情:害羞]」。
- **群聊**：两条没叫她的消息作为「群里刚才的消息」附在 @ 她的那条前面；她简短回答了在做什么。发现她把日记里的「上午」说成了「昨天」——已改成「日记里最近的一段（今天 10:05 写的）」。
- **主动发消息**：自由活动写完日记后提示出现了；那次日记是流水账（土豆丝炒糊、煮了米饭），她没发——符合规则。`phone_message` 本身没在真实模型上触发过。
- **夜间**：叫醒概率 0 时自动回「（睡着了……zzZ）」，半小时内第二条不再回；概率 1 时她被「吵醒」后正常聊天。DSH 重启后接着用当天的会话。
- 坑：DSH 进程里 Node 自带的 WebSocket 走全局代理，连不上 127.0.0.1（容器里），所以用 `node:http` 自己实现了一个极简客户端（`lib/ws-client.js`）。

## M0 里学到的东西（给以后的自己）

- **会话创建**：`ctx.sessionController.create({ sessionId, cwd, agentPreset })` + `resolveAgent(sessionId)`，
  然后 `agent.followup(createUserMessage(...))`。这正是 DSH 自带 schedule 插件的做法，宿主 API 面最小。
- **preset 子插件的工具**在 agent 看来是"继承的"，所以 `tools.restrict({ allow: [] })` 会连自己的工具一起藏掉；
  改用 `restrict({ deny: <全局工具名> })` + `tools.guard()` 白名单。
- `systemPrompt.suppressRuntimeContext()` 能去掉编程向的运行时上下文；`working-directory` 一段是必需的，去不掉（无害）。
- `end_free_time` 里调用 `exec.concludeTurn()` 直接结束这一轮，不需要模型再说一句话。
- 会话日志是多帧 zstd（`session.v4.jsonl.zstd`），解压时要跨帧读取。
- M2 实测：DeepSeek-V4.1-Flash 原生支持图片输入（V4-Pro 只支持文本）。工具结果里带图片要先 `attachments.saveImage()`
  再返回 `{ type: 'image', attachment }`。她看完图在小记里写到了「厨房的格子地砖」「雨把海面打出一层细纹」——文字观察里没有这些，
  说明她真的在看图。`defineTool` 的输出 schema 顶层不能写 `required`；这种错误在 inject 回调里会被静默吞掉，
  所以插件现在把日志写到 `plugin.log`。
- M1.5 实测：三次连续唤醒、0 个失败动作。她第一次用寄售箱，在日记里写「感觉像在跟海做买卖」。一开始她同时用 diary_write
  和 end_free_time 的 note 写了内容重复的两段，已在工具说明里提示「写过就别重复」。
- M1 实测：唤醒消息里带上「团子饿得喵喵叫；邮箱里来了包裹」后，她先喂猫、再做饭吃，然后取包裹、冒雨种菜、铺地毯、摆贝壳，
  8 步、约 2 万 token（计费输入约 3k）。**把「变化」放进唤醒消息，比让她自己到处查看省得多。**
- 第一次实测时世界描述里写了"院子尽头是沙滩"却没有沙滩这个地点，模型连试两次都失败、浪费行动次数——
  **世界描述里提到的地方必须真的能去**。
