# 小屋协议

## 伪代码

agent 通过 `house_do` 工具提交一段伪代码，人类可以在 `python -m littlehouse --repl` 里用同样的写法。

```
goto(沙滩); look()
pick(shell#1)
goto(客厅)；water(绿萝)        // 全角分号、全角括号也可以
say("今天的海很安静")
```

- 语句：`动作(参数, ...)`，用 `;`、`；` 或换行分隔；无参数时括号可省略（`look`）。
- 参数：裸词（`厨房`、`pot#1`）、数字、或带引号的字符串（`"..."`、`「...」`、`“...”`）。
- `//` 之后是注释。
- **顺序执行，遇到第一个失败就停下**，返回已执行部分的结果，方便 agent 重新规划。
- 每段最多 20 条语句、2000 个字符。解释器不会 `eval` 任何东西。
- **只写动作名、不写参数**（`cook`、`plant`、`sell`、`order`、`goto`……）会列出现在能填什么：能做的菜和缺的原料、背包里的种子和空菜地、
  能卖的东西和收购价、目录和价格、能去的地方。结果行用「？」标出，不算失败，后面的步骤照常执行。
- 做不了的动作会说怎么才能做：「这件事要在厨房做，先 goto(厨房)」「团子在卧室……可以 goto(团子) 走过去」「「邮箱」在庭院」「背包里没有「红烧肉」。可以在厨房 cook(红烧肉)」。
  `goto` 除了地点，也接受猫的名字（走到猫身边）和东西的名字（走到它所在的房间）。
- 每段脚本做完，结果末尾有一行「在厨房可以：recipes 看菜谱、cook 做菜……；可去：客厅」，列出当前位置能用的动作和简短说明。
- `look()` 里「这里能做」一行按当前位置和状态列出动作名（例如厨房：recipes、cook、eat、clean），另附随时能做的动作。
- **动作花真实的时间（M3）。** 一段脚本由小屋里的执行器（`house/littlehouse/tasks.py`）按游戏时钟一步步播放：
  走路按路程，做饭、打扫、钓鱼都要真的等那么久。`house_do` 等到整段做完才返回。

结果格式（每步一行标题 + 时间 + 缩进的描述；最后是期间发生的事和剩余时间）：

```
✓ goto(沙滩)  [08:03]
  你穿过庭院，来到了沙滩。
✓ fish()  [08:03–08:05]
  钓到了一条鲈鱼！
✗ pick(海星)  [08:05]
  这里没有「海星」。
期间：灶台上的萝卜汤炖好了。
现在 08:05，自由活动还剩 27 分钟（到 08:32）
```

### 动作时长

时长都在 `content.py` 里（`ACTION_SECONDS`、`RECIPES` 等），目标是「一圈想做的事」大约二十分钟。

| 动作 | 时长 | 说明 |
| --- | --- | --- |
| 走路 | 按路程，1 格 / 秒 | 和画面上走的完全一样（穿过门口）；相邻房间约 10 秒，卧室到沙滩约 25 秒。房间里走到要用的东西旁边也算 |
| `look` `help` `inventory` `recipes` | 0 | |
| `examine` `say` `call` | 5–10 秒 | |
| `water` `pick` `harvest` | 第一个 15 / 10 / 40 秒，之后每个 10 / 8 / 30 秒 | 挨个走过去做；做到一半被打断，剩下的没做 |
| `open` `read` `display` `feed` `pet` `catalog` `order` `sell` | 20–40 秒 | |
| `plant` `place` `stow` | 40–60 秒 | |
| `eat` | 一顿饭 2 分钟，零嘴 45 秒 | 在厨房会坐到木桌边 |
| `cook` 炒、煎 | 1–2 分钟，**一直守着** | 中途被打断（走开）菜会糊 |
| `cook` 拌 | 1 分钟 | 在台面上做，不占灶眼 |
| `cook` 煮饭、炖、蒸、烧、包饺子 | 先忙 30 秒–3 分钟，再**自己熟** 3–5 分钟 | 下锅后可以去做别的；好了以后她在厨房（或回到厨房）时自动盛出来；灶台两个灶眼 |
| `clean(分钟)` | 脏度 ÷ 25 分钟（最脏 4 分钟，最少 20 秒） | 进度保留在脏度里：扫了一半走开，下次只要扫剩下的；`clean(2)` 只扫两分钟 |
| `fish` | 每一竿 1–3 分钟（随机） | 被打断就什么也没钓到 |
| `rest` | 10 分钟 | 被打断按比例恢复精力 |
| `wait(分钟)` | 最多 30 分钟 | `wait()` 等到灶台上下一道菜好 |

### 菜谱（地道家常菜，`content.RECIPES`）

油盐酱醋糖、姜蒜、蚝油、香油默认厨房里有；表里的原料要自己种、钓，或者在订货目录上买。

| 菜 | 原料 | 做法与时间 |
| --- | --- | --- |
| 白米饭 | 大米 | 煮，先忙 30 秒，再自己煮 5 分钟，期间可以走开 |
| 荷包蛋 | 鸡蛋 | 煎，要一直守着，约 1.5 分钟 |
| 红烧肉 | 五花肉 | 炖，先忙 2 分钟，再自己炖 5 分钟，期间可以走开 |
| 番茄炒蛋 | 番茄、鸡蛋×2 | 炒，要一直守着，约 2 分钟 |
| 蛋炒饭 | 白米饭、鸡蛋、葱 | 炒，要一直守着，约 2 分钟 |
| 酸辣土豆丝 | 土豆×2 | 炒，要一直守着，约 2 分钟 |
| 蒜蓉菠菜 | 菠菜 | 炒，要一直守着，约 1 分钟 |
| 蚝油生菜 | 生菜 | 炒，要一直守着，约 1 分钟 |
| 醋溜白菜 | 白菜 | 炒，要一直守着，约 1.5 分钟 |
| 拍黄瓜 | 黄瓜 | 拌，约 1 分钟 |
| 番茄蛋汤 | 番茄、鸡蛋 | 煮，先忙 1 分钟，再自己煮 3 分钟，期间可以走开 |
| 萝卜炖排骨 | 萝卜、排骨 | 炖，先忙 2 分钟，再自己炖 5 分钟，期间可以走开 |
| 南瓜小米粥 | 南瓜、小米 | 煮，先忙 1 分钟，再自己煮 5 分钟，期间可以走开 |
| 清蒸鲈鱼 | 鲈鱼 | 蒸，先忙 1.5 分钟，再自己蒸 4 分钟，期间可以走开 |
| 干煎小黄鱼 | 小黄鱼 | 煎，要一直守着，约 2 分钟 |
| 红烧鱼 | 任意一条鱼 | 烧，先忙 2 分钟，再自己烧 4 分钟，期间可以走开 |
| 葱油饼 | 面粉、葱 | 煎，要一直守着，约 2 分钟 |
| 白菜猪肉饺子 | 面粉、猪肉馅、白菜 | 包，先忙 3 分钟，再自己煮 3 分钟，期间可以走开 |

**打断。** 新的脚本到达（REPL 里又输入了一段）、自由活动时间到了、DSH 里中止了这一轮，都会打断正在做的那一步，
由那一步自己决定做到一半意味着什么（见上表），后面的步骤丢弃。自由活动结束后不会再开始新的一步。

### 动作（M1.5）

很多动作的参数可省略：省略时作用于当前位置所有合适的东西（`water()` 浇这里所有植物和菜地，`pick()` 捡起这里所有东西，`harvest()` 收获这里所有熟了的作物，`display()` 把所有收藏品摆上架）。

| 分类 | 动作 | 说明 |
| --- | --- | --- |
| 观察 | `look()`、`help()`、`examine(东西)`、`inventory()` | `look()` 末尾有「这里能做」提示 |
| 移动 | `goto(地点)` | 自动寻路：客厅、厨房、卧室、庭院、沙滩 |
| 自己 | `eat(食物)`、`rest(沙发/床)`、`say(内容)` | 会饿、会累；`rest` 每小时最多恢复一次，偶尔会做梦 |
| 厨房 | `recipes()`、`cook(菜名)`、`wait()` | 菜谱见上表；偶尔做焦（累的时候更容易），偶尔格外好吃 |
| 家务 | `clean()`、`tidy(乱子)`（也可以写 `fix`）、`place(家具)`、`stow(家具)`、`water(植物)` | 房间会随时间落灰；打扫时偶尔在角落里有发现（越脏越可能）；家具要自己买 |
| 庭院 | `open(邮箱)`、`open(包裹)`、`plant(种子, 菜地)`、`harvest(菜地)` | 邮箱里是信，门口是快递包裹；作物要浇水、看季节，收成有多有少 |
| 买卖 | `catalog()`、`order(物品, 数量)`、`sell(物品, 数量)` | 在屋里翻目录下单，第二天 9 点后送到门口；在庭院把东西放进寄售箱，18 点后收走入账。**一贝币的购买力约等于一元人民币**：鸡蛋 1/个、大米 3/斤、五花肉 9/半斤、台灯 59；开拓署按略低于零售的价格收购作物、鱼和海边捡的东西（鲈鱼 18、粉色海螺 6），不收做好的菜 |
| 沙滩 | `pick(东西)`、`fish()`、`read(漂流瓶)` | 雨天贝壳和鱼更多；打雷不能钓鱼 |
| 收藏 | `display(收藏品)` | 摆到客厅收藏架 |
| 猫 | `call()`、`feed(食物)`、`pet()`、`play(玩具)`、`goto(团子)` | 团子会饿、会在屋里到处走（刚和它玩过、喂过、摸过的 10 分钟里不走）；亲密度影响叫不叫得动；每天的脾气不同（黏人 / 平常 / 傲娇 / 烦躁）。`play` 1–2 分钟：玩具可选（逗猫棒、小铃铛球、猫薄荷玩偶、毛线球可以订购；拆包裹会留下纸箱），它玩得开心 / 一般 / 没兴趣取决于当天脾气、饿不饿、刚玩过没有、是不是它最喜欢的玩具，还会随机发生和房间有关的事（跳上沙发、从木桌上跌下来、撞翻盆栽弄脏地板……）。**留下的乱子**（撒了一地的土、洒了一地的水、掉在地上的书 / 订货目录 / 靠垫、被踩乱的被子）是房间里的东西：`look()` 里看得到、画面上画得出，`tidy()` 或 `clean()` 收拾（10–60 秒一处），盆倒了要先扶起来才能浇水。没人看着的时候团子大约每天闯一次祸（脾气烦躁或饿的时候更多），会出现在「这段时间里」 |

物件可以用编号（`pot#1`）或名字（`绿萝`）指代；背包物品可以写名字的一部分（`萝卜` → `萝卜种子`，有歧义时会提示）。

做事会消耗精力（做饭 3、打扫 5、钓鱼 4 等），精力低于 5 时只能做不费力的事。

## 自由活动与平淡的日常（M3）

每天有几段**自由活动时间**（插件配置 `wake.slots`，默认早上 7:30–8:30、中午 11:30–12:30、傍晚 17:30–18:30 之间随机开始，
各 40 分钟；深夜 21:30–22:30 一段，一半的日子有）。这段时间由模型决定她做什么。

其余时间她**过平淡的日常**，由小屋自己安排（`content.IDLE_ACTIVITIES`）：每小时挑一件（窝在沙发上看书、窗边发呆、
在木桌边喝茶、书架前翻书、睡午觉、树下晒太阳、沙滩散步），走过去做；夜里（23–7 点）在床上睡觉。
这段时间里她不会饿过「有点饿」（饥饿上限 60），白天精力不低于 35，夜里睡觉恢复。
画面上画的就是她此刻在做的事。下一次自由活动开始时，唤醒消息会说「在这之前，你一直在过平淡的日常——刚才在……」。

### 世界随时间的变化

| 什么 | 规则 |
| --- | --- |
| 她自己 | 饥饿 +5/小时；精力 −3/小时；自由活动以外：饥饿最多 60、白天精力不低于 35、23–7 点睡觉 +12/小时 |
| 盆栽 / 菜地 | 水分每天 −30 / −50；下雨时菜地自动浇透 |
| 作物 | 浇过水且在适合的季节时才生长；成熟后产生「成熟了」的消息 |
| 房间 | 每天落灰 +6；猫所在的房间多一些；做饭让厨房 +8 |
| 团子 | 饥饿 +4/小时，到 80 时发出「喵喵叫」的消息；亲密度每天 −2；大约每小时换一个房间 |
| 开拓署 | 每周一 9 点后送基本补给（大米、鸡蛋、猫粮、牛奶）和一封信；新存档有一封欢迎信讲清楚规则 |
| 快递员阿陆 | 每天 9 点后送来已到期的订单；18 点后收走寄售箱并按收购价付贝币；偶尔留一封便条 |
| 小事件 | 大约每两天一件（起雾、海鸥、浮木冲上岸……），进入「你不在的时候」 |
| 沙滩 | 每天约 2 件（雨天 4 件）新东西冲上岸，最多 4 件 |

离开很久时最多补算 14 天。

## HTTP 接口

小屋进程只监听 `127.0.0.1`，启动时把 `{port, token, pid}` 写进 `<状态目录>/house.json`。
除 `/health` 外，所有请求都要带 `X-House-Token`；`Host` 必须是 `127.0.0.1` 或 `localhost`（防 DNS rebinding）。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/health` | `{ok, version, pid}`，无需令牌 |
| GET | `/look` | `{ok, text}` |
| GET | `/help` | `{ok, text}` |
| GET | `/events?since=…&actor=resident` | 事件（可按时间、角色过滤，最多 50 条）；唤醒时用来生成「上次醒着的时候，你……」 |
| GET | `/news?since=YYYY-MM-DDTHH:MM:SS` | 这之后「世界自己发生」的事（最多 20 条），用于唤醒时告诉她「你不在的时候」 |
| GET | `/state` | 完整世界状态（JSON） |
| GET | `/status` | `{free, free_until, busy, doing, idle, location}`：是否在自由活动、正在做什么、平时在做什么 |
| GET / POST | `/window` | 查看 / 打开关闭动画窗口：body `{open: bool, scale?: 1-4}`（没有 pygame-ce 时 501） |
| GET | `/screenshot?scale=1\|2` | 当前画面的 PNG（需要 pygame-ce，否则 501），同时存一份到 `world/latest.png` |
| POST | `/do` | body `{script, wait?}` → `{ok, done, id, text, results[]}`：按真实时间执行，最多等 `wait` 秒（默认 900）；没做完时 `done=false`，脚本继续执行 |
| POST | `/report` | body `{id, wait}` → 同上：接着等编号为 `id` 的脚本（插件每次最多等 240 秒，避开 Node fetch 的 5 分钟限制） |
| POST | `/interrupt` | 打断她正在做的事（DSH 中止这一轮时调用） |
| POST | `/session` | body `{free_until}`（epoch 秒；0 = 结束）→ 开始 / 结束自由活动；返回 `before`（她之前在做的日常） |
| POST | `/shutdown` | 存档并退出 |

POST 需要 `Content-Type: application/json`，body 上限 16 KB。

## 文件

`~/.dsh/little-house/`（插件可配置 `stateDir`）：

| 文件 | 内容 |
| --- | --- |
| `world/world.json` | 世界存档 |
| `world/events.jsonl` | 事件日志（追加写），记忆系统的原料 |
| `world/house.json` | 运行中小屋的端口与令牌（退出时删除） |
| `diary/YYYY-MM-DD.md` | 她的日记：每天一个文件，每段标注时间和来源（小屋 / QQ）。写不写由她决定 |
| `plugin.log` | 插件日志（超过 1 MB 轮换为 `.1`） |
| `world/latest.png` | 最近一次截图 |
| `plugin-state.json` | 今天的生活会话 id、今明两天投好的自由活动时间（`plans`）、已经结束的时段（`doneSlots`）、上次自由活动开始 / 结束时间 |

## 画面

两种方式，同一个渲染器（`house/littlehouse/render.py`，pygame-ce；家具、灶台、水槽、菜地土和番茄 / 土豆 / 萝卜 / 白菜 / 生菜 / 黄瓜用 LPC 素材，见 `house/littlehouse/assets/lpc/CREDITS.md`；素材文件缺失时退回代码绘制），都在**小屋进程内**：

| 方式 | 什么时候渲染 | 画面 |
| --- | --- | --- |
| 静态「瞥一眼」 | 只在 `house_render` / `GET /screenshot` 时渲染一帧 | 此刻的真实状态：走到一半就画在半路，在灶台边炒菜就有热气 |
| 动画窗口 | 只在窗口打开时（`view.bat`、`POST /window`、配置 `house.window`） | 同上，每一帧都是当时的状态；无人走动时降到 4 fps |

M3 以后动作本身就花真实时间，所以画面不再需要「回放」：`anim.current_pose(world)` 读执行器当前的阶段
（走路就按 1 格 / 秒沿路线插值，做事就画对应的特效），自由活动以外画她正在做的日常（看书、睡觉……）。
灶台上有菜在炖时会一直冒热气。

`house_render` 给模型的是 1280×872 的 PNG（DeepSeek 计约 600 token）。工具说明里提示她本机算力有限、偶尔看一眼即可。
