# 小屋协议

## 伪代码

agent 通过 `house_do` 工具提交一段伪代码，人类可以在 `python -m littlehouse --repl` 里用同样的写法。

```
goto(沙滩); look()
pick(shell#1)
goto(客厅)；water(绿萝)        // 全角分号、全角括号也可以
say("今天的海很安静")
```

- 语句：`动作(参数, ...)`，用 `;`、`；` 或换行分隔；无参数时括号可省略（`look`）。
- 参数：裸词（`厨房`、`pot#1`）、数字、或带引号的字符串（`"..."`、`「...」`、`“...”`）。
- `//` 之后是注释。
- **顺序执行，遇到第一个失败就停下**，返回已执行部分的结果，方便 agent 重新规划。
- 每段最多 20 条语句、2000 个字符。解释器不会 `eval` 任何东西。

结果格式（每步一行标题 + 缩进的描述）：

```
✓ goto(沙滩)
  你穿过庭院，来到了沙滩。
✗ pick(海星)
  这里没有「海星」。
```

### 动作（M1.5）

很多动作的参数可省略：省略时作用于当前位置所有合适的东西（`water()` 浇这里所有植物和菜地，`pick()` 捡起这里所有东西，`harvest()` 收获这里所有熟了的作物，`display()` 把所有收藏品摆上架）。

| 分类 | 动作 | 说明 |
| --- | --- | --- |
| 观察 | `look()`、`help()`、`examine(东西)`、`inventory()` | `look()` 末尾有「这里能做」提示 |
| 移动 | `goto(地点)` | 自动寻路：客厅、厨房、卧室、庭院、沙滩 |
| 自己 | `eat(食物)`、`rest(沙发/床)`、`say(内容)` | 会饿、会累；`rest` 每小时最多恢复一次，偶尔会做梦 |
| 厨房 | `recipes()`、`cook(菜名)` | 菜谱见 `content.py`；`#fish` 表示任意一条鱼；偶尔做焦（累的时候更容易），偶尔格外好吃 |
| 家务 | `clean()`、`place(家具)`、`stow(家具)`、`water(植物)` | 房间会随时间落灰；打扫时偶尔在角落里有发现（越脏越可能）；家具要自己买 |
| 庭院 | `open(邮箱)`、`open(包裹)`、`plant(种子, 菜地)`、`harvest(菜地)` | 邮箱里是信，门口是快递包裹；作物要浇水、看季节，收成有多有少 |
| 买卖 | `catalog()`、`order(物品, 数量)`、`sell(物品, 数量)` | 在屋里翻目录下单，第二天 9 点后送到门口；在庭院把东西放进寄售箱，18 点后收走入账 |
| 沙滩 | `pick(东西)`、`fish()`、`read(漂流瓶)` | 雨天贝壳和鱼更多；打雷不能钓鱼 |
| 收藏 | `display(收藏品)` | 摆到客厅收藏架 |
| 猫 | `call()`、`feed(食物)`、`pet()` | 团子会饿、会在屋里到处走；亲密度影响叫不叫得动；每天的脾气不同（黏人 / 平常 / 傲娇 / 烦躁） |

物件可以用编号（`pot#1`）或名字（`绿萝`）指代；背包物品可以写名字的一部分（`萝卜` → `萝卜种子`，有歧义时会提示）。

做事会消耗精力（做饭 3、打扫 5、钓鱼 4 等），精力低于 5 时只能做不费力的事。

### 世界随时间的变化

| 什么 | 规则 |
| --- | --- |
| 她自己 | 饥饿 +5/小时；精力白天 −3/小时，0–8 点（睡觉）+12/小时 |
| 盆栽 / 菜地 | 水分每天 −30 / −50；下雨时菜地自动浇透 |
| 作物 | 浇过水且在适合的季节时才生长；成熟后产生「成熟了」的消息 |
| 房间 | 每天落灰 +6；猫所在的房间多一些；做饭让厨房 +8 |
| 团子 | 饥饿 +4/小时，到 80 时发出「喵喵叫」的消息；亲密度每天 −2；大约每小时换一个房间 |
| 开拓署 | 每周一 9 点后送基本补给（大米、鸡蛋、猫粮、牛奶）和一封信；新存档有一封欢迎信讲清楚规则 |
| 快递员阿陆 | 每天 9 点后送来已到期的订单；18 点后收走寄售箱并按收购价付贝币；偶尔留一封便条 |
| 小事件 | 大约每两天一件（起雾、海鸥、浮木冲上岸……），进入「你不在的时候」 |
| 沙滩 | 每天约 2 件（雨天 4 件）新东西冲上岸，最多 4 件 |

离开很久时最多补算 14 天。

## HTTP 接口

小屋进程只监听 `127.0.0.1`，启动时把 `{port, token, pid}` 写进 `<状态目录>/house.json`。
除 `/health` 外，所有请求都要带 `X-House-Token`；`Host` 必须是 `127.0.0.1` 或 `localhost`（防 DNS rebinding）。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/health` | `{ok, version, pid}`，无需令牌 |
| GET | `/look` | `{ok, text}` |
| GET | `/help` | `{ok, text}` |
| GET | `/events?since=…&actor=resident` | 事件（可按时间、角色过滤，最多 50 条）；唤醒时用来生成「上次醒着的时候，你……」 |
| GET | `/news?since=YYYY-MM-DDTHH:MM:SS` | 这之后「世界自己发生」的事（最多 20 条），用于唤醒时告诉她「你不在的时候」 |
| GET | `/state` | 完整世界状态（JSON） |
| GET / POST | `/window` | 查看 / 打开关闭动画窗口：body `{open: bool, scale?: 1-4}`（没有 pygame-ce 时 501） |
| GET | `/screenshot?scale=1\|2` | 当前画面的 PNG（需要 pygame-ce，否则 501），同时存一份到 `world/latest.png` |
| POST | `/do` | body `{script}` → `{ok, text, results[]}`；执行后立即存档 |
| POST | `/shutdown` | 存档并退出 |

POST 需要 `Content-Type: application/json`，body 上限 16 KB。

## 文件

`~/.dsh/little-house/`（插件可配置 `stateDir`）：

| 文件 | 内容 |
| --- | --- |
| `world/world.json` | 世界存档 |
| `world/events.jsonl` | 事件日志（追加写），记忆系统的原料 |
| `world/house.json` | 运行中小屋的端口与令牌（退出时删除） |
| `diary/YYYY-MM-DD.md` | 她的日记：每天一个文件，每段标注时间和来源（小屋 / QQ）。写不写由她决定 |
| `plugin.log` | 插件日志（超过 1 MB 轮换为 `.1`） |
| `world/latest.png` | 最近一次截图 |
| `plugin-state.json` | 今天的生活会话 id、唤醒次数、上次唤醒时间 |

## 日记工具

由 `dsh-little-house/diary` 提供，可以挂进任意 preset（`config.source` 标注来源）：

| 工具 | 说明 |
| --- | --- |
| `diary_write(entry)` | 往今天的日记里追加一段（最多 2000 字） |
| `diary_read(day?)` | 读某天的日记：今天 / 昨天 / 前天 / YYYY-MM-DD |
| `house_rest(note?)` | 结束活动；note 可选，写的话也进日记 |

## 画面

两种方式，同一个渲染器（`house/littlehouse/render.py`，pygame-ce 程序化像素画，无外部素材），都在**小屋进程内**：

| 方式 | 什么时候渲染 | 画面 |
| --- | --- | --- |
| 静态「瞥一眼」 | 只在 `house_glance` / `GET /screenshot` 时渲染一帧 | 她站在最近一次动作的位置，动作定格在半途（水滴、热气、爱心……）；15 分钟前的动作不再显示 |
| 动画窗口 | 只在窗口打开时（`view.bat`、`POST /window`、配置 `house.window`） | 按顺序回放她的动作：沿门口走过去、做动作；积压太多时加速，最多落后约 12 秒；无人走动时降到 4 fps |

每个成功的动作都会产生一个「节拍」（`world.beats`，只在内存里）：走过的路点（经过门口）、动作名、目标物件。
`anim.py` 把节拍变成姿态（位置、朝向、走路帧、特效），`render.render(world, t, pose)` 画出来。

`house_glance` 给模型的是 1280×872 的 PNG（DeepSeek 计约 600 token）。
